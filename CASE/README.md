# CASE

This folder stores dated research notes discovered by the maintenance heartbeat.

The daily maintenance loop is:

1. search for new sources
2. judge whether they are valuable for this project
3. save valuable findings here
4. update the project when a low-risk, high-confidence change is justified
5. run validation
6. commit and push the branch to GitHub

Use it for high-value signals related to:

- AI control of DWSIM
- DWSIM Automation3 and .NET automation
- Python orchestration for process simulation
- AI agents for process engineering and digital twins
- reproducible process simulation workflows
- repository maintenance practices that directly improve this project

Each note should include:

- date
- source links
- concise summary
- relevance to AI-DWSIM-Skill
- recommended project action
- whether a code or documentation update is warranted

Do not save low-confidence, duplicate, or weakly related search results here.
